# GLDNet
GLDNet is a lightweight CNN combining residual blocks, SE attention, and a non-local module to capture both local details and global context, enhancing feature representation for classification tasks.

This code corresponds to the paper: Uncovering Dual Pathway Interaction in Human Cognition: From EEG Evidence to AI Model Design.
The environment configuration is python = 3.8.17, numpy = 1.24.4, and torch = 2.0.0.
